# Contributing

Thank you for your interest in this project. All contributions, bug
reports, bug fixes, documentation improvements, enhancements, and ideas
are welcome.

## How to contribute

1. Fork the repository.
2. Create a new branch for your change (`git checkout -b my-change`).
3. Make your changes and commit them with a clear message.
4. Push your branch to your fork.
5. Open a pull request describing what you changed and why.

## Reporting bugs

If you find a bug, please open an issue that includes:

- A clear description of the problem
- Steps to reproduce it
- What you expected to happen versus what actually happened

## Code style

Keep changes small and focused. Add comments where the logic isn't
obvious, and update the README if your change affects how the script is
used.

By contributing, you agree that your contributions will be licensed
under the same license as this project (see [LICENSE](LICENSE)).
